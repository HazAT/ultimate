Shows what each agent is doing right now (exploring, editing, verifying…) next to its name (needs a TypeSafe key).

Working-phase labels, classified by Jev after each tool round. It needs `classify`, which needs `TYPESAFE_API_KEY` in Secrets. Transcript excerpts leave the machine (see [classify](../classify/README.md)).

One background durable task per conversation asks over the latest request and the work since it: up to its last 15 tool calls and latest assistant text (never earlier runs or a branch's inherited history). Answers are memoized and bound to their run (its first input, which survives Pi's per-round generation handovers); confidence below 0.6 keeps the previous phase within that run. Interrupted requests are abandoned on restart, never resent. Provider errors never fail the main run. Yielding or starting a new run clears the displayed phase in the root `ultimate.conversation-phases` document, retaining the in-flight lock until the task settles.

The phase shows on busy branch rows, and in lower case in place of "working" on @ultimate's sidebar row (and its top-bar button on phones) and the other standing-agent rows (other residents). Waiting on subagents and idle are derived locally, not classified, so Waiting shows whenever `phase` is enabled, even without a key; with `phase` disabled no row shows a phase.

With `plan` enabled, the same request also asks about each unconfirmed acceptance criterion of the conversation's newest open epic (`plan`'s `openCriteria`): not started, in progress or looks done, with the earlier estimate. Answers at 0.7 confidence or more go to `plan`'s `estimate`, which only raises them; a looks done records the last entry of the tool round that scheduled the request, which is also where its excerpt ends. Criteria text then also leaves the machine.
